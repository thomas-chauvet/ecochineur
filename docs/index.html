A simple filter that respects your Vinted search

EcoChineur adds the filters you choose to the Vinted search you are viewing. Your search text, price, sort order, condition and the brands and materials you already picked stay as they are.

Curated brands

French, European, mixed and eco-conscious brands. A brand is listed only with a documented reason and a verified Vinted identifier.

Natural materials

Linen, cotton, wool, silk, cashmere, alpaca, mohair or merino, with or without brand filters.

Conservative merge

brand_ids[] and material_ids[] are added without removing anything already selected. Reset unchecks your choices and removes only those two filters.

Private by design

EcoChineur collects no data and does not use, sell or share user data for any purpose.

No backend

No server, no remote code, and no network calls made by the extension itself. All data is bundled.

Minimal permissions

Only storage and activeTab: the extension sees the current tab only after you click its icon.

Local preferences

Your choices and language stay in chrome.storage.local on your device.

Referenced data

The database grows through reviewed contributions. Suggest a brand (GitHub account required).

Install from source

Until the Chrome Web Store release, you can build the extension yourself (Node.js 22.22 or later).

  1. Clone the GitHub repository.
  2. Run npm install, then npm run build.
  3. Open chrome://extensions and enable Developer mode.
  4. Click "Load unpacked" and select the dist/ directory.
  5. Open a Vinted catalog search, then click the EcoChineur icon.
