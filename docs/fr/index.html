Un filtre simple qui respecte votre recherche Vinted

EcoChineur ajoute les filtres choisis à la recherche Vinted affichée. Le texte recherché, le prix, le tri, l'état et les marques et matières déjà choisies sont conservés.

Marques sélectionnées

Marques françaises, européennes, mixtes et éco-responsables. Chaque marque est référencée avec une justification documentée et un identifiant Vinted vérifié.

Matières naturelles

Lin, coton, laine, soie, cachemire, alpaga, mohair ou mérinos, avec ou sans filtre de marque.

Fusion prudente

brand_ids[] et material_ids[] sont ajoutés sans rien retirer. La réinitialisation décoche vos choix et ne retire que ces deux filtres.

Privée par conception

EcoChineur ne collecte aucune donnée et n'utilise, ne vend ni ne partage aucune donnée utilisateur.

Aucun serveur

Pas de backend, pas de code distant, aucune requête réseau propre à l'extension. Toutes les données sont intégrées.

Permissions minimales

Seulement storage et activeTab : l'extension ne voit l'onglet actif qu'après un clic sur son icône.

Préférences locales

Vos choix et votre langue restent dans chrome.storage.local sur votre appareil.

Installer depuis les sources

En attendant la publication sur le Chrome Web Store, vous pouvez construire l'extension vous-même (Node.js 22.22 ou plus récent).

  1. Clonez le dépôt GitHub.
  2. Exécutez npm install, puis npm run build.
  3. Ouvrez chrome://extensions et activez le mode développeur.
  4. Cliquez sur « Charger l'extension non empaquetée » et sélectionnez le dossier dist/.
  5. Ouvrez une recherche du catalogue Vinted, puis cliquez sur l'icône EcoChineur.
