Un filtre simple qui respecte les choix existants sur Vinted

EcoChineur ajoute les filtres sélectionnés à l'URL Vinted active tout en préservant les filtres existants : recherche, prix, tri, état, marques et matières.

Marques référencées

Les marques ne sont intégrées que lorsque leur identifiant Vinted est vérifié. La version de développement inclut Armor Lux, Faguo et Veja.

Matières naturelles

Sélectionnez lin, coton, laine, soie, cachemire, alpaga, mohair ou mérinos pour enrichir une recherche Vinted.

Fusion conservative

`brand_ids[]` et `material_ids[]` sont ajoutés sans supprimer les identifiants déjà présents.

Privée par conception

EcoChineur ne collecte aucune donnée et n'utilise aucune donnée utilisateur à des fins d'analyse, de publicité, de profilage, de mesure d'audience, d'entraînement de modèles, de partage ou de revente.

Aucun backend

L'extension n'a pas de serveur et n'effectue aucun appel réseau qui lui soit propre.

Aucune télémétrie

Aucune analyse, aucun pistage, aucun pixel, aucun beacon, ni mesure d'utilisation.

Préférences locales

Les options cochées et la préférence de langue restent dans `chrome.storage.local` sur l'appareil de l'utilisateur.

Données référencées dans la version de développement

La base de données intégrée est volontairement réduite : seules les entrées avec un identifiant Vinted vérifié sont publiées.

Installer la version de développement

La version actuelle est destinée à des tests locaux depuis le dépôt GitHub.

  1. Téléchargez ou clonez le dépôt GitHub.
  2. Exécutez `npm install`, puis `npm run build`.
  3. Ouvrez `chrome://extensions` et activez le mode développeur.
  4. Cliquez sur "Charger l'extension non empaquetée" et sélectionnez le dossier `dist/`.
  5. Ouvrez `https://www.vinted.fr/catalog`, puis ouvrez EcoChineur.
