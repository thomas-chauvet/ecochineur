Suggérer une marque

Une marque mérite sa place ?

Sans compte. Chaque suggestion est vérifiée par un mainteneur, qui consigne les preuves avant d'ajouter la marque.

1. Vinted doit la connaître

EcoChineur filtre avec les identifiants de marque de Vinted : la marque doit apparaître dans le filtre Marque d'une recherche Vinted. Si vous avez ouvert cette page depuis l'extension en filtrant déjà cette marque, son identifiant est prérempli.

2. Choisir la catégorie

  • Fabriqué en France (avec ou sans Origine France Garantie)
  • Fabriqué en Europe, hors France
  • France et autres pays européens uniquement
  • Éco-responsable, production partout

3. Donner les preuves

Sites de production, certifications (GOTS, B Corp, Fair Wear…), programmes de réparation ou rapports environnementaux. Une affirmation invérifiable ne suffit pas.

Le formulaire n'est pas disponible pour le moment. Suggérez la marque sur GitHub (compte GitHub requis).

Le formulaire est hébergé par Tally (Belgique). Il ne reçoit que ce que vous saisissez, ainsi que l'identifiant et le domaine Vinted affichés dans le formulaire. Vous préférez GitHub ? Ouvrez une issue.
